## 2. Drive Torque — แรงขับและแรงบิด
ตัวแปร: m = มวลรถ (kg), g = 9.81 m/s², α = มุมทางลาด (deg), Crr = สัมประสิทธิ์ต้านการกลิ้ง, v = m/s, t_acc = เวลาเร่ง (s), n = จำนวนมอเตอร์, r = รัศมีล้อ (m), SF = ตัวคูณแรงออกแบบ

\`\`\`text
F_grade = m g sin(α)             [N]
F_roll  = Crr m g cos(α)         [N]
a       = v / t_acc              [m/s²]
F_acc   = m a                    [N]
F_design = (F_grade + F_roll + F_acc) × SF  [N]
T_motor = F_design × r / n       [N·m]
P_wheel = F_design × v           [W]
P_elec  = P_wheel / η            [W]
I_batt  = P_elec / V             [A]
\`\`\`

**ตรวจความสัมพันธ์:** หากมุม, ความเร็ว, เวลาเร่ง, รัศมีล้อ, จำนวนมอเตอร์และ SF คงที่ เมื่อมวลเพิ่ม 300→400 kg ค่า T จะต้องเพิ่มในอัตรา 400/300 = 1.3333 เท่า ไม่ใช่ลดลง เหตุที่ What-if V53.8.74 แสดงลดลงคือ Baseline กับ Scenario เคยใช้ค่ามุมทางลาดคนละชุด (แก้แล้ว)

ข้อจำกัด: มอเตอร์ 1500 W ไม่ได้ยืนยันว่าให้แรงบิดที่จุด RPM นั้นได้จริง ต้องดู Torque-Speed curve, กระแส Controller และการยึดเกาะของล้อ

## 3. Ramp — 55, 280, 290 cm
\`\`\`text
h = 55 cm, x = 280 cm, L_measured = 290 cm
L_calculated = √(55² + 280²) = 285.351 cm
α = atan(55/280) = 11.113°
Grade = (55/280) × 100 = 19.643%
|L_measured - L_calculated| = 4.649 cm
\`\`\`

**19.643% ไม่ใช่ 19.643°** หากโจทย์ของรถกำหนดออกแบบสำหรับทางลาด 19° นั่นคืออีกกรณีที่ชันกว่าทางลาดที่วัด ควรตรวจทั้ง 11.11° และ 19° แยกกัน

## 4. Main Battery 72 V — พลังงานต่อรอบ
\`\`\`text
ระยะทางไป-กลับ = 2 × ระยะทางเที่ยวเดียว
ระยะราบต่อรอบ = 2 × (ระยะเที่ยวเดียว − ระยะลาดต่อเที่ยว)
F_flat = Crr m g
F_up   = m g sinα + Crr m g cosα
F_down,drive = max(0, Crr m g cosα − m g sinα)
E_segment [Wh] = F [N] × distance [m] / (3600 × η)
E_drive,cycle = E_flat,cycle + E_up,cycle + E_down,cycle + E_turn,cycle
E_aux,total = P_aux × t_runtime [h]
E_total,model = E_drive,cycle × N_completed + E_aux,total
Ah_design = E_total,model × (1+Reserve) / (V × DoD)
\`\`\`

ค่า E_down ของมอเตอร์ขับอาจเป็นศูนย์เมื่อแรงโน้มถ่วงช่วยให้รถไหลลง แต่ **พลังงานทางราบในเที่ยวกลับยังมีอยู่** และระบบควบคุม/เบรกไม่ได้พิสูจน์ว่าใช้ไฟศูนย์ทั้งหมด

**ประเด็นสำคัญที่ยังต้องแก้:** สูตรใช้ N_completed เป็นจำนวนรอบเต็มที่ทำได้ในเวลาทำงาน แล้วไม่รวมพลังงานขับของรอบสุดท้ายที่อาจวิ่งไปบางส่วน (ในขณะที่ Auxiliary คิดเต็มเวลาทำงาน) จึงมีโอกาสประเมินแบตต่ำกว่าการใช้งานจริง ต้องกำหนดให้หยุดเมื่อครบรอบ หรือเพิ่ม Partial Cycle / Conservative Allowance สำหรับเลือกซื้อแบต

**ทำไม Ah อาจลดลงเมื่อน้ำหนักเพิ่ม:** ถ้าโหลดเพิ่มทำให้วินช์ยกช้าลง จำนวนรอบใน 3 ชั่วโมงลดลง และรถได้วิ่งรวมระยะสั้นลง ค่า Wh รวมอาจลด ถึงแม้ Wh ต่อการวิ่งหนึ่งรอบจะเพิ่มขึ้น ต้องแสดงจำนวนรอบประกอบเสมอ

## 5. Winch 12 V — Interpolation / เวลา / Ah
ตัวอย่าง Load 100 kg, ระยะยก 1.5 m, ข้อมูล First Layer ระหว่าง 0 และ 454 kg

\`\`\`text
r = (100-0)/(454-0) = 0.220264
v_up = 3.3 + r(2.5-3.3) = 3.123789 m/min
I_up = 12 + r(60-12) = 22.572687 A
t_up = (1.5/3.123789) × 60 = 28.811 s
E_up = (12 × 22.572687 × 28.811) / 3600 ≈ 2.168 Wh
E_event = E_up + E_down  [1 งาน = ขึ้นหนึ่งครั้ง+ลงหนึ่งครั้ง]
E_total = E_event × จำนวนงานยก
Ah_design = E_total (1+Reserve)/(12 × DoD)
\`\`\`

แบบจำลอง Conservative ถือ Down = Up เป็นสมมติฐาน ไม่ใช่ผลทดสอบจากผู้ผลิต การม้วนสลิงมากกว่าชั้นแรกเปลี่ยนความเร็วและแรงดึง ต้องตรวจตามชั้นและ Datasheet จริง รวมทั้งกระแสขณะ Start/Stall

## 6. Stability 4 ด้าน
เมื่อมวลรวม 300 kg, Boom 20 kg, Payload 100 kg, W=WB=1.1 m, L=1.2 m, Kdyn=1.2, สมมติส่วนรถที่เหลือ 180 kg และ CG ส่วนรถอยู่กึ่งกลาง

\`\`\`text
LEFT (θ=-90°):
M_O = (20×9.81×0.05) + (100×9.81×1.2×0.65) = 774.99 N·m
M_R = (180×9.81×0.55) = 971.19 N·m
SF = 971.19/774.99 = 1.253 < 1.5   => FAIL

FRONT (θ=0°):
M_O = 100×9.81×1.2×0.25 = 294.30 N·m
M_R = 180×9.81×0.55 + 20×9.81×0.35 = 1039.86 N·m
SF ≈ 3.533

REAR (θ=±90°):
M_O = 0 ในแบบจำลองและมุมดังกล่าว (ไม่ใช่ความปลอดภัยอนันต์ของรถจริง)
M_R ≈ 1147.77 N·m
\`\`\`

มวล/ตำแหน่ง CG เสาเครน ฐานหมุน วินช์ และโครงรถในโหมดพื้นฐานถูกรวมไว้ในมวลรถส่วนที่เหลือ สมมติ CG แขนอยู่กึ่งกลาง L/2; ถ้า CG จริงไม่อยู่จุดนั้น สูตรต้องเปลี่ยนตามตำแหน่งจริง

## 7. Uphill rear tipping
\`\`\`text
W_parallel = m g sinα
W_normal = m g cosα
F_inertia = m a (ต้านทิศเร่งขึ้นลาด)
M_O = (W_parallel + F_inertia) × h_CG
M_R = W_normal × d_R
SF = M_R/M_O
\`\`\`

นี่เป็นรูปแบบแรงสมมูลของรถแข็งบนทางลาด ไม่ใช่การจำลองความสะเทือนหรือการเหวี่ยงของโหลดที่แขวนบนเครน ระยะ d_R และ h_CG ต้องมาจากจุดศูนย์ถ่วงจริงของรถในสภาพขับขึ้นลาด

## 8. What-If / การส่งค่าข้ามโมดูล
\`\`\`text
m_total = m_base + m_boom + m_payload
\`\`\`
เมื่อเพิ่ม Payload ในโหมดง่าย โปรแกรมต้องเพิ่มมวลรวมที่ใช้โดย Torque และ Battery และนำมวลใหม่ไปคำนวณ Stability ขณะที่ระยะฐานล้อ ความชัน/ความเร็ว และ Geometry อื่นต้องคงเดิม ยกเว้นตั้งค่าความสัมพันธ์เฉพาะไว้ การเพิ่ม 100 kg จากมวลเดิม 300 kg ทำให้มวลรวม 400 kg **เกินเป้าหมายรถไม่เกิน 300 kg**

## 9. BMS — จุดผิดจริงที่แก้ใน V53.8.77
ก่อนแก้ หน้า Design Check และ Battery+BMS ใช้เกณฑ์ Continuous / Peak ต่างจาก Battery Selection และบางหน้าไม่ได้รวมกระแสอุปกรณ์เสริมที่ทำงานพร้อมกัน

หลังแก้:
\`\`\`text
I_cont,main = max(I_uphill, I_pivot) + I_aux
I_peak,main = max(I_cont,main, I_torque_design + I_aux)
I_aux = P_aux / V
\`\`\`
**ข้อควรระวัง:** กระแสจำกัดฝั่ง Phase/Motor ของ VESC ไม่ใช่กระแส DC Battery โดยตรง และไม่มีข้อมูลกระแส Startup/Stall ของวินช์พอที่จะสรุป Winch BMS Peak = PASS; จึงแสดง CHECK

## 10. ประเด็นที่ยังต้องแก้ก่อนใช้ยืนยันแบบจริง

1. **Mass invalid:** กรอกมวลรวมต่ำกว่า Boom + Payload ได้ และโปรแกรมใช้ max(0, m_total−m_boom−m_payload) ซ่อนมวลฐานติดลบ ต้องบล็อกผล PASS/รายงานเมื่อข้อมูลไม่สอดคล้อง
2. **Partial final cycle:** คำนวณพลังงานขับเฉพาะรอบเต็ม อาจประเมินแบตเตอรี่ต่ำสำหรับการทำงานต่อเนื่อง 3 ชั่วโมง
3. **Physical validation:** แรงบิดที่ RPM ใช้งานจริง, แรงยึดเกาะ, CG จริง, shock, cantilever/frame stiffness, rope-layer speed, Winch BMS stall current และความเอียงข้างยังไม่ยืนยัน
4. **Differential turning:** ค่า Cturn เป็นค่าสมมติ ต้องวัดจริงกับล้อและพื้นคอนกรีต
5. **CG vs mass:** โปรแกรมไม่ได้เดา CG ใหม่เมื่อเพิ่มโหลดหรือเปลี่ยนแขน ต้องกำหนดข้อมูลตำแหน่งจริงเพิ่มเติม
