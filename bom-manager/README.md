# BOM Manager — รถไฟฟ้าพร้อมเครน

โปรแกรมเว็บหน้าเดียวสำหรับแก้รายการ BOM, กรอกราคา, คิดยอดรวม และบันทึกข้อมูล BOM เป็น GitHub commit เพื่อดูประวัติย้อนหลัง

## เปิดใช้งานบน Windows

1. ติดตั้ง Python 3 หากเครื่องยังไม่มี
2. ดับเบิลคลิก `run_local.bat`
3. เบราว์เซอร์จะเปิด `http://localhost:8000`
4. กด **โหลดข้อมูลจาก GitHub** เพื่อดึงรายการล่าสุด

## เชื่อมและบันทึก GitHub

1. สร้าง Fine-grained Personal Access Token ใน GitHub โดยเลือกเฉพาะ repository นี้
2. ให้สิทธิ์ **Contents: Read and write** เท่านั้น
3. ในโปรแกรมกด **ตั้งค่า GitHub** ตรวจ owner/repository, branch และ path
4. วาง token แล้วกด **ใช้การตั้งค่านี้**
5. แก้รายการและกด **บันทึกเป็น commit**

Token ใช้ในหน่วยความจำของแท็บปัจจุบันเท่านั้น ไม่ถูกเขียนลงไฟล์ BOM หรือ local storage; ปิด/รีโหลดแท็บแล้วต้องใส่ใหม่ โปรแกรมส่ง token ไปยัง GitHub API เพื่ออ่านและบันทึกไฟล์เท่านั้น

ไฟล์ BOM ที่โปรแกรมแก้คือ `bom-manager/bom.json` การบันทึกจะสร้าง commit ใน GitHub พร้อมสรุปจำนวนรายการที่เพิ่ม/แก้/ลบ และเปิด commit ล่าสุดได้จากแถบสถานะ

## สำรอง/ส่งออก

- ปุ่ม **ดาวน์โหลด JSON** สำรองข้อมูลตามรูปแบบ BOM
- ปุ่ม **ส่งออก CSV** ส่งรายการไปเปิดใน Excel
- ฉบับร่างที่ยังไม่ commit จะเก็บใน local storage ของเบราว์เซอร์เครื่องนั้น

รายการที่ยังไม่มีสเปกพอเลือกซื้อจะยังไม่มีลิงก์ซื้อ และมีเหตุผลกำกับในหมายเหตุ
