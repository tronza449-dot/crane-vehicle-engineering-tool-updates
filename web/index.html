Differential / Pivot Turn Energy

Turning model: s_turn=(W/2)φ และ E_turn=Cturn·m·g·s_turn/(η×3600). Cturn เป็นค่าประมาณของการไถลยาง/ล้อพยุงบนพื้นจริง ควรปรับจากการวัดกระแสจริงภายหลัง
Simple Cycle: เที่ยวเดียว = ทางราบ + ทางลาด • เที่ยวไปคิดทางราบ + ขึ้นลาด • เที่ยวกลับคิดลงลาด + ทางราบ • ไม่คิดพลังงานช่วงออกตัว และไม่นำพลังงานจากทางลงมาหักคืนแบตเตอรี่

Project Summary

ภาพรวมสถาปัตยกรรมและขอบเขตการออกแบบ CAR ANIMAL

01

Vehicle Platform

รถไร้คนขับสำหรับขนย้ายซากสัตว์ ใช้ Hub Motor 2 ตัวแบบ Differential Steering และมีล้อ Support เพิ่มเติม

02

Crane & Winch

เครนติดรถหมุนซ้าย/ขวา ±90° มี Limit Switch ป้องกันหมุนเกิน และใช้วินช์ 12 V แยกแหล่งจ่ายจาก Main Battery

03

Electrical Architecture

Main Battery 72 V → Dual VESC → Hub Motors พร้อม ESP32 สำหรับ Control Logic, IMU, Receiver และ Safety Interlock

04

Safety Logic

E-stop ตัดการทำงานทันที, IMU ตรวจ Tilt, Drive/Crane มี Interlock และ Limit Switch จำกัดมุมเครน

05

Engineering Calculations

เว็บรองรับ Drive Torque, Battery Energy, Winch Battery และ Stability/Tipping พร้อมสูตร แทนค่า และคำอธิบาย

06

Web Architecture

Desktop CVET รัน Web Server บนเครื่อง และสามารถเปิด HTTPS Public Link ผ่าน Tailscale Funnel สำหรับมือถือหรือคอมเครื่องอื่น
